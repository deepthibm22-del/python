## Pillars of OOPS   
To work with Real time entity, the pillars of OOPs are very important.   
4 Pillars of OOPS   
  1. Inheritance   
  2. Polymorphism   
  3. Encapsulation   
  4. Abstraction   
   
1. Inheritance   
    Inheritance is a process of deriving properties from one class to another   
    There are two types of class:    
      - Parent Class   
          Super/base class   
      - Child Class   
    Types of Inheritance   
      1. Single Level Inheritance   
          It an inheritance where a single child class inherits from it's parent class.   
          ```
          class Parent:
          	x = 10
          class Child(Parent):
          	y = 20
          	def display():
          		print(x+y)
          ```
      2. Multi Level Inheritance   
      3. Multiple Inheritance   
      4. Hierarchical Inheritance   
      5. Hybrid Inheritance
