# Recursion   
A Recursion is a case where a function repeatedly call itself until a particular base condition (Termination Condition) is satisfied   
***Syntax***:   
```
def fname(par1, par2,..., par_n):
	if Base_condition:
		return [val]
	Statement Block
	return fname(arg1, arg2,..., arg_n)

print(fname(arg1)

```
