1. Python – Number-Based Programs
Program 1: Reverse a Number
num = int(input("Enter a number: "))
rev = 0while num > 0:   
 digit = num % 10    
rev = rev * 10 + digit   
 num = num // 10
print("Reverse is:", rev)



Example: 1234 → 4321

num = int(input("Enter a number: "))
count = 0if num == 0:    
count = 1else:   
 while num > 0:        
count = count + 1

Program 4: Palindrome Number
num = int(input("Enter a number: "))
original = num
rev = 0
while num > 0:    
digit = num % 10    
rev = rev * 10 + digit    
num = num // 10
if original == rev:    
print("Palindrome")else:    
print("Not a palindrome")



Example: 121 → Palindrome
